## 0. 全局编码规范（所有任务必须遵守，DoD 缺一不可）

| 编号 | 规范 | 说明 |
|---|---|---|
| W-01 | 提示词/上下文注入：KV 缓存命中优化 | 前缀字节稳定：系统提示固定前置、工具 schema 顺序稳定、历史追加式增长；禁止在历史前中段插入/重排；不稳定内容（时间戳/运行状态/序号）一律置尾（架构文档 §13.1） |
| W-02 | 提示词/上下文注入：注意力机制优化 | 最重要的约束（权限边界/调用协议/失败语义/硬性规则）同时置于任务文本开头（首段）与系统提示末尾（重申），中间段仅放过程性信息；关键结论由 report 摘要回传（§13.1） |
| W-03 | 工具提示词：官方标准英文 | 工具 description/参数说明使用与官方一致的标准英文写法：第一句"何时调用"，随后前置条件、失败语义（超时/拒绝/护栏错误）、副作用（阻塞/插队/持久化）；精炼（单条 description 目标 ≤ 120 tokens），提升调用精准性并减少上下文（§13.2） |
| W-04 | 语言约定 | 代码注释、JSDoc、README、AGENTS.md 与全部文档使用**中文**；代码标识符、工具 description 与面向模型的提示词按 W-03 使用英文；关键时序/协议注释必须说明"为什么"（§13.3） |
| W-05 | 零官方包运行时依赖 | 所有 @deepseek-ai/* 服务经 ctx.get() 运行时解析；唯一第三方运行时依赖 @huggingface/transformers（§1 原则） |
