## 示例（examples/）

展示 DeepSeek Harness 主要接口和扩展点的可运行演示。每个子目录负责自己的配置、前置条件、命令和详细行为（按需查阅）。

- 通过通用 MCP 客户端连接受支持第三方记忆服务器的可选 overlay。详见[记忆示例参考](mcp-memory/README.md)。需要开发MCP相关服务时，可以阅读。

- 非交互式 agent（智能体）：接受一项任务并运行，然后以选定的机器可读或人类可读格式输出结果。详见[无头示例参考](headless-agent/README.md)。需要开发后台服务型无头agent时，可以阅读。

- 由 Python SDK 和 JSON-RPC 驱动的无人值守编码 agent。详见 [JSON-RPC 示例参考](jsonrpc-agent/README.md)。需要无人值守的自动化服务，可以阅读。

- 能够检查并更改内存中 Cordis 插件树的自指 agent。详见 [web-cordis 示例参考](web-cordis/README.md)。需要进行插件的配置叠加相关开发，可以阅读。

- 演示了定时任务/后台任务（如 ctx.jobs）在 Web 环境中的整合方式。详见 [示例](web-schedule/README.md)。需要 agent 具备定时调度能力时，可以阅读。

- 面向程序化客户端的 ACP（Agent Client Protocol）自动化服务器，支持会话、权限和取消操作。详见 [ACP 示例参考](acp-agent/README.md)。当需要构建无界面自动化 agent 服务时，可以阅读。
