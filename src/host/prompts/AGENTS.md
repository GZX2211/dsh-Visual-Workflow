# Prompts Module Rules

## 范围与职责

适用于 `src/host/prompts/`。**提示词编写规范以同目录 `README.md` 为准**，只在需要编写或修改提示词内容时读取 README.md。

作为全插件提示词组装的**唯一基线**：把编排事实与稳定模板结构组装成注入给模型的文本——父代理指令、子代理任务块、协作清单、规划提示词、运行期通知。

判断归属：该修改是否改变「注入给模型的文本如何由事实组装」？若是纯粹的 Agent 语义判断、工具 Schema / 可见性、或运行态事实（状态、锁、生命周期），应放到对应模块。

## 组装与依赖

- 构建器是纯计算：入参即全部输入，同入参必同输出；图推导、节点上下文、预算口径等事实由调用方或本模块的纯计算提供，构建器不自行读图、读盘、读设置。
- 动态值只允许出现在末段；不得把不稳定内容注入稳定前缀。

## 测试补充

- 断言只引用导出的约束常量与段落锚点，不硬编码提示词正文文案：文案修订不应破坏基线测试。
- 结构变更必须同步更新基线测试；禁止通过放宽断言掩盖输出变化。

## 核心原则

1. 提示词基线单一来源；文案规范以 `README.md` 为准。
2. 输出即契约：结构可重构，但字节必须可证不变。
3. 纯函数：无时钟、无随机、无 IO、无隐式全局状态。
4. 共享措辞与锚点单一源，变体之间不复制模板。
5. 处于依赖链末端，不反向依赖运行时模块。
